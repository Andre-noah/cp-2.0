# Кассетный плеер как приложение (PWA)

В этой папке всё, что нужно, чтобы плеер можно было установить на телефон из Chrome как приложение.

## Файлы
- `index.html` - сам плеер (кассета, эквалайзер, индикаторы уровня)
- `manifest.webmanifest` - название, иконки, режим «на весь экран», горизонтальная ориентация
- `sw.js` - работа без интернета после первого открытия
- `icons/` - иконки приложения
- `.nojekyll` - служебный файл для GitHub Pages (необязательный)

## Как выложить на GitHub Pages (бесплатно)
1. Зайдите на github.com, нажмите **New repository**. Имя, например, `cassette-player`, тип **Public**. Галочки README и .gitignore не нужны. Нажмите **Create repository**.
2. На странице нового репозитория нажмите **uploading an existing file**. Распакуйте архив и перетащите в окно браузера **все файлы и папку `icons`** (папку тоже можно перетащить целиком). Внизу нажмите **Commit changes**.
3. Откройте **Settings -> Pages**. В пункте **Source** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
4. Через 1-2 минуты вверху страницы Pages появится адрес вида `https://ВАШ_ЛОГИН.github.io/cassette-player/`.

## Установка на телефон
1. Откройте этот адрес в Chrome на телефоне (интернет нужен только в первый раз).
2. Меню с тремя точками -> **Установить приложение** (или **Добавить на главный экран** -> **Установить**).
3. Иконка появится на главном экране. Приложение запускается без адресной строки, на весь экран и в горизонтальной ориентации.

## Обновление
Заменили файлы в репозитории? Откройте `sw.js` и поменяйте в первой строке `const CACHE = 'cassette-v1'` на `'cassette-v2'` (потом `v3` и так далее). Тогда телефоны скачают новую версию. На телефоне приложение нужно закрыть и открыть заново.

## Если пункта «Установить приложение» нет
- Адрес должен начинаться с `https://`.
- Обновите страницу и подождите минуту: Chrome проверяет страницу не сразу.
- Откройте адрес именно в Chrome, а не во встроенном браузере другого приложения.
- Проверьте, что в репозитории лежат все файлы, в том числе `manifest.webmanifest`, `sw.js` и папка `icons`.

## Что стоит знать
- Музыку выбирайте кнопкой «Добавить аудио» (файлы остаются на телефоне).
- Шрифты Google подгружаются из интернета при первом открытии, потом сохраняются. Без них интерфейс выглядит так же, меняется только вид букв в списке.
- Воспроизведение при выключенном экране в таком виде работает не на всех телефонах. Для надёжной фоновой работы позже нужна обёртка Capacitor (следующий шаг к приложению для магазинов).
